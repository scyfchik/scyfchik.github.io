# Скриншоты The Last Shift

Поместите сюда изображения WebP, JPG или PNG. В `src/data/developmentProject.js` укажите имя файла вместо `null` в поле `screenshots[].file`, например `"gameplay.webp"`. Названия слотов локализованы. Галерея и lightbox подключат изображение автоматически; отсутствующие или повреждённые файлы показывают плейсхолдер.
